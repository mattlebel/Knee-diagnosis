# Runner Knee Map

A single-page tool for mapping running knee pain:

1. **When in the stride**: an animated runner (seen from the right side). Pause or scrub to the moment it hurts and mark that gait phase.
2. **Where on the knee**: tap pins on a right-knee diagram (outside, front, back and inside views).
3. **How it feels**: symptom chips (downhill, stairs, swelling, clicking, the km where it started, and so on).

It ranks common running knee conditions (ITBS, lateral meniscus, popliteus, biceps femoris, LCL, tibiofibular joint, fibular nerve, patellofemoral pain and others), with self-checks and strengthening exercises for each.

Open `index.html` in a browser. No build step.

This is a self-assessment aid, not a diagnosis.
